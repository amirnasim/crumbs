# ۱- راهنمای وضعیت قابلیت‌ها

این سند برای هر قابلیت یک وضعیت مشخص ثبت می‌کند. وضعیت‌ها بر اساس کد فعلی، routeها، مدل‌ها، سرویس‌ها، تنظیمات و اسکریپت‌های موجود تعیین شده‌اند.

| وضعیت | تعریف عملیاتی |
| --- | --- |
| فعال | قابلیت در کد پیاده‌سازی شده، route یا سطح استفاده مشخص دارد و بدون نیاز به سرویس خارجی خاص در محیط مناسب پروژه قابل استفاده است. |
| فعال و وابسته به تنظیمات خارجی | قابلیت پیاده‌سازی شده اما استفاده واقعی از آن به تنظیمات، `credential`، `provider` یا زیرساخت خارجی وابسته است. |
| اختیاری | قابلیت در کد وجود دارد اما فعال‌سازی آن انتخابی است و برای اجرای مسیر اصلی پروژه الزامی نیست. |
| زیرساخت آماده | مدل، سرویس، `task` یا ساختار فنی وجود دارد، اما قابلیت به‌صورت کامل در UI عمومی یا جریان عملیاتی اصلی exposed نشده است. |
| Legacy | قابلیت برای سازگاری با داده‌ها یا مسیرهای قدیمی نگهداری شده و در جریان عمومی فعلی کاربر استفاده نمی‌شود. |
| خارج از دامنه | قابلیت در کد فعلی پیاده‌سازی نشده و نباید به‌عنوان امکان موجود پروژه معرفی شود. |
