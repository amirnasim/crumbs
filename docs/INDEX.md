## مقدمه

این سند مرکز ناوبری مستندات پروژه Crumbs است. هدف آن این است که خواننده بداند هر سند چه کاربردی دارد، برای چه مخاطبی نوشته شده و در چه ترتیبی بهتر است مطالعه شود.

`README.md` نقطه ورود repository است. `docs/INDEX.md` راهنمای مسیر مطالعه و ارجاع بین مستندات رسمی و عملیاتی پروژه است.

## ترتیب مطالعه پیشنهادی

1. ابتدا `README.md` برای شناخت سریع پروژه مطالعه شود.
2. سپس `docs/01-معرفی-پروژه.md` برای درک دامنه، اهداف و وضعیت پروژه خوانده شود.
3. بعد از آن `docs/02-امکانات-پروژه.md` برای شناخت قابلیت‌های واقعی بررسی شود.
4. برای شناخت فنی، `docs/03-معماری-سیستم.md` مطالعه شود.
5. برای بهره‌برداری عملیاتی، `docs/04-راهنمای-مدیر-سایت.md` خوانده شود.
6. برای آماده‌سازی تولید، `docs/06-راهنمای-استقرار.md` و سپس اسناد عملیاتی launch مطالعه شوند.
7. برای توسعه، `docs/07-راهنمای-توسعه.md` مبنای استانداردهای کدنویسی قرار گیرد.
8. برای تغییرات داده، `docs/08-مستندات-Database.md` مطالعه شود.
9. برای routeها و flowهای HTTP، `docs/09-مستندات-API.md` خوانده شود.
10. برای کنترل کیفیت، `docs/10-راهنمای-تست.md` مطالعه و اجرا شود.
11. در پایان، `CHANGELOG.md` برای تاریخچه نسخه و سیاست شماره‌گذاری بررسی شود.
12. اسناد عملیاتی متناسب با نیاز deployment، backup، migration، observability یا launch استفاده شوند.
